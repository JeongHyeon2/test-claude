# 움직이는 표본

CSS·SVG 필터·Canvas로 만든 열 가지 움직임을, 원리와 함께 표본처럼 늘어놓은 수집장.
**열 개 전부 만질 수 있습니다** — 끌고, 문지르고, 눌러 보세요.

**https://jeonghyeon2.github.io/test-claude/**

| 표본 | 기법 | 조작 |
| --- | --- | --- |
| 01 진자 파동 | CSS | 가로로 문지르면 시간이 감김 |
| 02 메타볼 | SVG 필터 | 커서가 여섯 번째 방울이 됨 |
| 03 모아레 | CSS | 커서로 각도·배율 조율 |
| 04 무리 짓기 | Canvas | 커서를 따라옴 · 누르면 흩어짐 |
| 05 물결 격자 | CSS | 파문의 진원이 커서로 이동 |
| 06 흐름장 | Canvas | 커서 주위 소용돌이 · 클릭 → 궤적 지우기 |
| 07 로렌츠 끌개 | Canvas | 끌어서 시점 회전 |
| 08 정육면체 | CSS | 끌어서 직접 굴리기 |
| 09 생명 게임 | Canvas | 끌어서 세포 그리기 · 더블클릭 → 새로 파종 |
| 10 트뤼셰 타일 | Canvas | 지나가면 타일 뒤집힘 · 클릭 → 새로 깔기 |

조작은 포인터 이벤트로 배선해 마우스와 터치에서 모두 동작하고,
모션을 끈 상태에서도 살아 있습니다 (정지 중에는 조작할 때마다 한 프레임씩 다시 그림).

# 활자 견본실

한글과 라틴을 나란히 놓고 크기·자간·행간·굵기를 직접 움직여 보는 활자 견본지.

**https://jeonghyeon2.github.io/test-claude/**

## 구성

- `index.html` — 움직이는 표본 (첫 장)
- `specimen.html` — 활자 견본실
- 둘 다 프레임워크·빌드 단계 없음
- `.github/workflows/deploy-pages.yml` — 푸시하면 GitHub Pages로 배포
  (루트의 `*.html` 만 올립니다)

## 설계 메모

| 항목 | 값 |
| --- | --- |
| 디스플레이 | Bodoni Moda (라틴 전용) |
| 한글 | Pretendard Variable |
| 데이터·사양 표기 | IBM Plex Mono |
| 바탕 | Porcelain `#eef0f3` / 다크 `#0e1014` |
| 강조 | Ultramarine `#2b3ce8`, Coral `#ff7a6b` |
| 그리드 | 여백 사양표 13rem + 본문 1fr |

- 라이트/다크는 토큰만 재정의합니다. `prefers-color-scheme`과 `[data-theme]` 양쪽에 대응합니다.
- 히어로 뒤 하프톤 망점은 Canvas로 그리고 커서에 반응합니다.
- `prefers-reduced-motion: reduce`에서는 등장 연출과 망점 애니메이션이 모두 멈춥니다.
- 한글이 어절 중간에서 끊기지 않도록 `word-break: keep-all`을 적용했습니다.

# FrameSpeed

블랙박스 영상에서 자차 속도를 추정한 결과를 열어 보고 인용하는 업무 화면.
앞의 두 장과 달리 **빌드가 필요한 앱**이라 `framespeed-web/` 에 따로 두었고,
GitHub Pages 에는 올라가지 않습니다.

## 화면

| 경로 | 화면 | 하는 일 |
| --- | --- | --- |
| `#/` | 사건 목록 | 조회 번호로 사건을 불러와 표로 훑음 |
| `#/case/{조회번호}` | 사건 상세 | 판정 · 속도 그래프 · 구간 · 근거 프레임 · 사건 정보 |
| `#/new` | 새 분석 접수 | 영상 1차 검사 (확장자 · 용량 · 길이 · 해상도 · SHA-256) |

해시 라우팅이라 정적 호스팅에서 새로고침해도 404 가 나지 않습니다.

## 설계 메모

| 항목 | 값 |
| --- | --- |
| 뼈대 | React 18 + Vite 5 |
| 그래프 | Recharts (`src/components/SpeedChart.jsx`) |
| 데이터 | Supabase REST · **읽기 전용** |
| 한글 | Pretendard Variable |
| 기준 글자 | 14px — 홍보 페이지가 아니라 하루에 몇 번씩 여는 도구라서 |

- 속도 그래프에 마우스를 올리면 그 시점의 속도 · 추정 범위 · 가감속 · 오차와
  속한 구간(가속/정속/감속)이 함께 뜹니다. 감속 구간은 배경에 옅게 깔아
  마우스를 올리기 전에도 브레이크 시점이 먼저 보이게 했습니다.
- 숫자는 고정폭(`tabular-nums`)이라 표를 세로로 훑을 때 자릿수가 흔들리지 않습니다.
- 영상 해시(SHA-256)를 전문 그대로 띄우고 복사 버튼을 답니다 — 분석한 영상이
  제출 영상과 같은 파일인지 확인하는 근거입니다.
- 보관 만료일을 남은 일수와 함께 띄우고, 지난 건은 화면 맨 위에서 먼저 알립니다.

## 사건 목록이 브라우저에만 남는 이유

브라우저에 실린 anon 키로는 `jobs` 표를 통째로 읽을 수 없습니다(RLS).
그래서 조회 번호로 불러온 사건만 `localStorage` 에 쌓아 목록으로 보여줍니다.
사건 내용은 저장하지 않고 표에 쓸 몇 줄만 둡니다 (`src/store.js`).
계정별 사건 목록은 서버에서 내려줘야 합니다.

## 아직 서버가 필요한 것

이 앱은 DB 를 **읽기만** 합니다. 실제 접수 · PDF 생성 · 전문가 검토 신청 ·
정확도 피드백은 모두 쓰기라 서버가 있어야 합니다. 근거 프레임 이미지도
비공개 저장소에 있어 서버가 발급한 링크로만 열립니다.
권한 문제가 아니라 설계입니다 — 브라우저에 실린 키에는 쓰기 권한이 없습니다.
각 화면 맨 아래 접힌 안내에 같은 내용이 적혀 있습니다.

## 로컬에서 돌리기

```bash
cd framespeed-web
cp .env.example .env      # VITE_SUPABASE_URL · VITE_SUPABASE_ANON_KEY 채우기
npm install
npm run dev
```

이 저장소는 public 이라 `.env` 는 올리지 않습니다.
anon 키는 브라우저에 실리는 게 정상이지만(방어선은 키가 아니라 DB 의 RLS 와 GRANT),
저장소에 두지는 않습니다. `service_role` 키는 어떤 경우에도 여기 두지 않습니다.
